CycleQuest 手机端（离线）
========================

安装
----
1. 把 CycleQuestMobile.apk 传到安卓手机（微信/QQ/数据线都行）。
2. 在手机文件管理器里点开，允许“安装未知应用”。
3. 安装后桌面会出现 CycleQuest 图标。

第一次使用
----------
1. 电脑打开 CycleQuest.exe。
2. 工具 → 手机文件 → 导出今日任务。
3. 把下载的 cyclequest-today-YYYY-MM-DD.json 发到手机。
4. 手机 App → 导入电脑文件 → 选这个 json。
5. 勾选今天完成的；过去的日子只能看，不能改。

晚上回传
--------
1. 手机 App → 导出完成。
2. 选“下载”保存 cyclequest-done-YYYY-MM-DD.json。
3. 把这个文件发回电脑。
4. 电脑：工具 → 手机文件 → 导入手机完成。

规则
----
- 电脑是主库，手机是副本。
- 手机只能把“今天未完成”改成“完成”，不能改回未完成，不能改文字，不能补历史。
- 补卡仍然只在电脑上做。
- 手机没有网络权限，数据只存在手机本机。
- 每天记得导出一次；跨天未导出的完成不会自动上传。

数据在哪
--------
手机数据存在 App 私有目录 state.json，卸载 App 会一起删除。
重要数据请每天导出 done.json 回电脑，电脑会自动备份。

重新打包 APK
------------
双击“重新打包APK.bat”，会调用 Android Studio 的 Gradle 重新生成并复制 APK。

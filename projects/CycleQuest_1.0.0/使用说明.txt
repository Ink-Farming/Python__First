CycleQuest 2.0
==============

双击 CycleQuest.exe 启动。
第一次启动会稍微慢几秒，之后会打开一个没有地址栏的独立窗口。

【五个分区】
总览   今天的进度、补卡名额、近期考试节点
任务   每日 / 每周 / 每月任务，勾选后自动保存
数据   历史记录、补卡入口、单日明细
工具   补全缺失周期、排序与一致性校验、立即备份
报告   生成年度执行报告（点了才运行）

【补卡规则】
- 每天 2 个名额；周六、周日 3 个。
- 名额当天有效，不用就作废，不累积。
- 只能补过去的日子，不能补今天和未来。
- 只能补最近一个还有未完成任务的日期；这一天补完，才能继续往前一天。
- 补卡直接算完成，不额外标记，也不能撤销。
- 补卡顺序和名额由程序校验，不是只写在界面上。

【文件说明】
CycleQuest.exe        主程序
app_data.json         你的任务数据（不要删）
app_data.backup-*.json 自动备份，保留最近 40 份
makeup_log.json       补卡名额使用记录（不要手改）
report.html           生成过的报告（可删，会重新生成）

【换电脑 / 备份】
把整个“任务系统2.0”文件夹拷走即可，数据和程序都在里面。
关闭窗口后，后台服务会在几分钟内自动退出。

【打不开时】
1. 确认 Windows 里有 Microsoft Edge。
2. 检查 app_data.json 是否还在、是不是合法 JSON。
3. 看同目录下有没有 cyclequest.log，里面会写启动错误。

【手机端（离线 APK）】
安装：把“手机端\CycleQuestMobile.apk”传到安卓手机，点开安装；需要允许“未知来源”。
用法：
1. 电脑：工具 → 手机文件 → 导出今日任务。
2. 把 json 发到手机（微信/QQ/数据线）。
3. 手机 App：导入电脑文件。
4. 勾选今天完成的；过去的日子只能看，不能改。
5. 手机：导出完成，把 json 传回电脑。
6. 电脑：工具 → 手机文件 → 导入手机完成。
规则：手机只改今天；电脑是主库；手机不能补历史，补卡仍在电脑上做。

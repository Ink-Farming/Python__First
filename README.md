# 🐍 Python 练习代码仓库

> 个人 Python 学习与练习代码归档

## 📖 项目简介

这个仓库是我学习 Python 过程中的练习代码集合，主要用于记录和巩固所学知识。代码涵盖基础语法、数据结构、算法、第三方库使用等各个方面。

## 🛠 环境要求

- Python 3.x（建议 3.8 及以上）
- 依赖库（如有）：
  ```
  -因为是基础学习，所有无第三方库的使用
  ```

## 🚀 如何使用
克隆仓库到本地：
```
git clone https://github.com/Ink-Farming/Python__First.git
```
进入对应目录，直接运行 Python 文件：
```
python example_file_name.py
```
